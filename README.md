# Buy Me A Coffee (Web3 Praise Board)

## Project Overview
This project contains a decentralized "Praise Board" for creators.

## Smart Contract
The smart contract `PraiseBoard.sol` is deployed on the Ethereum Sepolia Testnet.
**Deployed Address:** `0x0FaebD0cfA6f15CA041e304111C3590d3B6C3b2b`

## Setup
To run this project:
1. `npm install`
2. `npm run dev`
3. Navigate to `/praise-board`

## Features
- Tip amount via ETH.
- Send a note up to 256 characters.
- See the wall of supporters updated live from on-chain event logs.
